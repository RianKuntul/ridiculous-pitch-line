A one-sentence startup pitch — an entry for make.fun's
[Ridiculous at First Glance, Real by the Second](https://make.fun/bounty/u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a)
competition.

> We match daters by what they both hate, then charge restaurants to host the first date — couples bonded by a shared enemy order more dessert than happy couples do.

## Run

```sh
node main.ts
```

This writes the pitch to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`),
then re-reads it and refuses to exit cleanly unless it holds 1–200 characters
of non-whitespace text. Node 22, no dependencies, no network.
